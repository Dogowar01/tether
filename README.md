# Tether

A quiet mental wellness companion for difficult moments.

Tether is a native mobile app (iOS & Android) built with Expo and React Native. It offers four grounding tools designed to feel like a trusted notebook, not a wellness brand.

## Tools

- **The Witness** — Write what can't be said. Hold it privately or let it go.
- **State Map** — A short nervous system check-in with a guided grounding exercise.
- **The Container** — Write something down, choose a vessel to hold it, and set it down safely.
- **Anchors** — Your personal library of sensory and memory-based grounding points.

## Stack

- React Native / Expo (managed workflow)
- expo-router (file-based navigation)
- AsyncStorage (local persistence)
- Reanimated v3 (animations)
- Playfair Display (typography)

## Development

```bash
npm install
npx expo start
```

Open in Expo Go on your device by scanning the QR code.
